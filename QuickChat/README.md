# QuickChat Application

## Description
QuickChat is a Java-based messaging application developed for PROG5121. It features user authentication, messaging functionality with formatted IDs, hashing, and status reports.

## Features
- Message creation and validation
- Message ID generation and hashing
- Unit testing with JUnit 5
- Automated build and execution flow

## Setup & Running
1. Open the project in Apache NetBeans IDE.
2. Build the project using `Clean and Build`.
3. Run `QuickChat.java` to start the application.
4. Run `MessageTest.java` to execute unit tests.
